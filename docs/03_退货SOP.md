# 退货与售后处理 SOP

> 示例文档，用于演示知识库结构；实际判定标准以公司售后制度为准。
> 用途：客服处理退货、售后的标准流程，避免口径不一。

## 一、退货判定表

| 情形 | 可否退 | 责任方 | 处理方式 |
|---|---|---|---|
| 商品质量问题 | 可退 | 公司 | 全额退款 + 承担运费 |
| 发错货 | 可退 | 公司 | 全额退款 + 承担运费 + 补发 |
| 运输破损 | 可退 | 公司 / 物流 | 全额退款，同时向物流索赔 |
| 买家不想要 | 可退 | 买家 | 退款但扣运费 |
| 超过退货窗口 | 不可退 | — | 视情况给优惠券安抚 |
| 人为损坏 | 不可退 | 买家 | 拒绝，需留存证据 |

## 二、标准处理流程

1. 买家发起退货 → 客服 24 小时内响应
2. 判定责任方 → 按上表执行
3. 退款操作 → 财务 3 个工作日内完成
4. 记录归档 → 登记退货台账，注明原因分类

## 三、升级规则

- 单笔金额超过 200 美元 → 需主管审批
- 买家投诉至平台介入 → 立即升级主管
- 同一买家 30 天内退货 2 次以上 → 标记为高风险买家

## 常见坑

- 退货原因必须按平台规定的类目归类，否则平台指标会算错
- 退款后务必确认库存回补，否则账实不符
- 运输破损要先留证再退款，否则无法向物流索赔
